# Agriculture Data Analysis

## Project Overview
This project analyzes agricultural data to identify the factors affecting
production, revenue, yield, and profit.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings
- Most profitable crop: Sugarcane
- Best irrigation method: Drip
- Best season: Kharif
- Best state by average profit: Punjab
- Strongest numerical relationship with profit: Revenue
- Revenue-Profit correlation: 0.887

## Analysis
The project includes data cleaning, exploratory data analysis,
correlation analysis, and visualization.
